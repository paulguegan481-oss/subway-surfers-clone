# Subway Dash + classement Supabase

Projet modifié pour envoyer un score avec pseudo et afficher les 10 meilleurs.

## Configuration
Dans `main.js`, remplace `SUPABASE_URL` et `SUPABASE_ANON_KEY` par l'URL et la clé publique (anon/publishable) de ton projet Supabase. Ne place jamais une clé secrète/service-role dans le navigateur.

Crée la table et les policies avec le SQL fourni dans la conversation. Puis envoie les fichiers à GitHub Pages.

Le jeu est un site statique : aucun serveur Node permanent n'est nécessaire.
